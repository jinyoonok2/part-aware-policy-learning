# Project milestone report prompt

Prepare a 3–4 page project milestone report in the CoRL LaTeX format.

Provided template: [CoRL LaTeX template](https://drive.google.com/file/d/1I5OcBFBqK4UA10Mj6Ez4gCIqmOEh3MH6/view).

Extracted template directory: [CoRL_camera_ready_template_2024](CoRL_camera_ready_template_2024/).

The unused original template ZIP was removed during repository cleanup; the
edited paper, style and bibliography sources remain in the directory above.

Working report source: [part_aware_pose_milestone.tex](CoRL_camera_ready_template_2024/part_aware_pose_milestone.tex).

The report must include the following components:

- Title, Authors.
- Introduction: Introduce the problem and your plan to approach this problem.
- Related Work: Describe the related works and how they relate to your project.
- Problem Definition: Describe the input, output, and other variables to define your problem. Specify the data you are using and the expected evaluations.
- Technical Approach: Describe the methods you tried or intend to apply to your problem.
- Preliminary Results: Describe the current state of the project and your results so far.
- Appendix: GenAI use, if any. The appendix may have an unlimited number of pages.
